# Blackwood Dukeall Hall

A first-person, sit-on rotary lawnmower simulator set on the grounds of a
decaying Georgian estate. Golden hour to dusk: mow the great lawn, drive the
gravel drive, crack a beer, smoke a cigar, and watch the light go.

Built in Godot 4.7 with an authored, procedurally-generated asset pipeline in
headless Blender. Every asset passes a deterministic visual-QC gate before it
is allowed into the game.

## Gameplay

- Sit-on rotary mower: suspension, wheel contacts, kerb bumps, grass-deck interaction
- First-person viewmodel: both hands grip the bottle and cigar while you drive
- Beer slosh physics with a level-driven liquid surface, foam, and condensation beads
- Cigar ash and ember simulation with wind
- Mow-grid coverage tracking (per-cell cut state, height, and colour)
- 15-minute golden-hour-to-dusk cycle: moving sun, rising mist, headlights that actually help
- Estate world: Georgian hall with a breached wing, iron fence and gate, hedges,
  dry fountain, oak/beech/dead trees, 160 m striped lawn, gravel drive with wheel ruts

## Running

Requires Godot 4.7+ (GL Compatibility renderer recommended on CPU-only hosts).

```bash
godot --headless --import .   # first time only
godot .                       # play
godot . -- --harness          # deterministic capture run (evidence/frames/)
```

Unit tests (Gut):

```bash
godot --headless --path . -s res://addons/gut/gut_cmdln.gd \
  -gdir=res://tests -ginclude_subdirs -gexit
```

## The asset pipeline

Assets are generated by scripted Blender builds (`scripts/build_*.py` in the
3D source tree, exported as GLB into `assets/`). Each asset goes through
multi-round visual QC: a deterministic headless Cycles rig renders fixed
review angles to `evidence/qc/`, and every round is gated by an independent
visual review before the next fix round. Nothing ships as programmer art:
lofted bodywork, boolean-punched window openings, baked edge-wear attributes,
layered worn paint, and composition-aware ground textures are all authored
geometry and bakes. `evidence/qc/qc_log.md` records the verdicts.

`evidence/qc/` in this repo keeps the final approved round of every asset plus
first-round captures for before/after comparison.

## Repo layout

```

audio/     synthesized engine, birds, ambient loops
scenes/    main scene
scripts/   gameplay: mower physics, mow grid, slosh, cigar, day/night, HUD, harness

evidence/  QC captures and harness frames

```

## Performance note

The harness runs at ~20 fps under Xvfb with llvmpipe (pure CPU rendering, no
GPU) on the development machine. On any real GPU the scene is comfortably
real-time; the CPU number is a floor, not a target.
